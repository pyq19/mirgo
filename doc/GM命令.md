# GM 命令手册

Go 服务端 GM 命令表驱动移植自 Delphi `TPlayObject.ProcessUserLineMsg`
（ObjBase.pas:7188-8600）与 `g_GameCommand` 命令表（M2Share.pas:2724-2926）。
注册总数 157 条（含 1 条权限载体哑条目），另有 `/who`、`/total` 聊天前缀命令。

## 通用规则

- **触发**：聊天行以 `@` 开头进入命令分发；`/who`、`/total` 以 `/` 开头单独分发。
- **参数分隔**：空格、`:`、`,`、TAB 均可作分隔符（GetValidStr3 语义，连续分隔符合并），最多 7 个参数。
- **大小写**：命令名不区分大小写（中文字面量除外）。
- **`?` 帮助**：第一个参数以 `?` 开头时输出 `命令格式: @<命令> <参数格式>`。
- **权限**：0-10 分级（登录时 AdminList 按角色名+IP 授权，运行时 `@setpermission` 可改）。权限不足反馈分三种，下表"权限"列标注：
  - `N`：提示"权限不够..."（默认）；
  - `N(静)`：静默无反馈（Delphi 实现内硬编码退出）；
  - `N(兜)`：与未知命令相同提示（Delphi 调试段门槛语义）。
- **未知命令**：红字 `@<命令> 此命令不正确，或没有足够的权限！！！`。
- **改名与调权**：所有命令的默认字面量与权限可被 `serverconfig/server.jsonc`
  的 `commands.names` / `commands.permissions`（Command.ini 转译表，键为 Delphi
  字段名，如 `AdjuestTLevel`/`Auth`/`Spirit`）覆盖。下表列出**默认字面量**。
- 标注 ★ 的为 Go 专属命令（Delphi 无对应）；标注"扩展"的为 Go 在 Delphi 语义上的增强。

## 未移植命令（4 条）

| 命令 | 原因 |
|------|------|
| `@ReloadRobot` / `@ReloadRobotManage` | Go 无机器人子系统（Delphi Robot.txt/TRobotObject） |
| `@Reconnection` | 语义为令客户端换网关重连（SM_RECONNECT）；Go 单端口架构无网关可换 |

命令级行为细节（与 Delphi 的逐条差异、原版怪癖、Go 增强）见各 `cmd/server/gmcmd_*.go` 头注与函数注释。
