# UI 调试

调试控制台提供行业标准两层 UI 调试能力:**叠加层**(包围盒/实际图素)与**悬停拾取**(inspector)。

## 打开控制台

反引号 `` ` `` 切换,跨场景生效。打开后按键全部交给控制台;`help` 列命令,`↑↓` 翻历史。

## 命令速查

| 命令 | 作用 |
|------|------|
| `ui bounds` | 可见控件包围盒线框(按钮=绿、窗口=蓝、网格=黄)+ 光标下控件名字 |
| `ui imgs` | 在每个可见控件位置绘制其绑定的 WIL **实际图像**,独立于常态渲染——常态被抑制的控件(如底栏按钮仅按下时画面)也能看到真实图素 |
| `ui inspect` | 悬停拾取:白框高亮光标下控件 + 一行属性 `路径 (类型) [x,y w×h] vis=… wil=文件:索引` |
| `ui pick` | 把光标下控件的一行属性打印到控制台(同写日志,可回溯) |

叠加层在场景之后绘制;同开多层时线框压在图像之上。

## 典型流程

**这块像素是哪个控件/哪张图?**

```
ui inspect        # 光标移上去:白框 + 一行属性
ui pick           # 需要抄录时打进控制台
```

**图素索引/位置对不对?**

```
ui imgs           # 看控件绑定的实际 WIL 图
ui bounds         # 对照命中矩形与图素范围
```

## 适用范围

`ui *` 与叠加层在 Notice / Login / SelectChr / Play 四个有 UI 的场景全部生效(场景 `Open()` 注册活动 UI),无 UI 的占位场景会提示 no UI。
